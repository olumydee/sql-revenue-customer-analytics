# SQL Revenue & Customer Analytics

This project analyzes revenue performance, customer behavior, and profitability using SQL.  
It demonstrates end‑to‑end data analysis skills including data cleaning, transformation, KPI calculation, and business insight generation.

---

## 📊 Project Objectives
• Analyze revenue trends across products, regions, and time  
• Identify high‑value and at‑risk customers  
• Calculate KPIs such as total revenue, average order value, retention, and churn  
• Use SQL window functions to evaluate customer behavior over time  
• Provide insights that support business decision‑making  

---

## 🛠 Tools & Technologies
• SQL (CTEs, joins, aggregations, window functions)  
• PostgreSQL / MySQL (any SQL engine)  
• GitHub for version control  

---

## 📁 Key SQL Techniques Used
• Common Table Expressions (CTEs)  
• INNER / LEFT JOINs  
• Window functions (ROW_NUMBER, RANK, LAG)  
• Aggregations (SUM, AVG, COUNT)  
• Date/time functions  
• Subqueries  

---

## 📈 Business Questions Answered
• Which products generate the highest revenue?  
• What is the trend of monthly/quarterly revenue?  
• Who are the top customers by lifetime value?  
• What is the retention rate across customer cohorts?  
• Which customer segments are declining or growing?  

---

## 🔍 Insights & Findings (Sample)
• Revenue increased steadily over the last 6 months  
• A small percentage of customers contributed a large share of revenue  
• Customer churn was highest among low‑frequency buyers  
• Repeat customers had significantly higher average order value
